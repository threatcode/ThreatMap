# Browser Authentication Example

This example demonstrates how to authenticate with a Threatmap instance using browser-based authentication.

## Usage

1. Install dependencies:

   ```bash
   pnpm install
   ```

2. Run the example:

   ```bash
   pnpm start
   ```

3. Follow the instructions displayed in the console to complete authentication in your browser.

## Environment Variables

- `THREATMAP_INSTANCE_URL` - The URL of your Threatmap instance (default: `http://localhost:8080`)
